# Health App Privacy Analyzer

A Python-based project for analyzing privacy and security indicators in Android health applications.

## Project Goal

The goal of this project is to help identify privacy-sensitive permissions, third-party trackers, security findings, and other indicators that may require further investigation in health-related Android applications.

## Planned Features

- Identify sensitive Android permissions
- Categorize permissions by privacy risk
- Analyze third-party trackers and SDKs
- Organize CWE/security findings
- Compare multiple health applications
- Generate a summarized privacy and security report

## Technologies

- Python
- Android APK analysis
- MobSF
- Static Analysis
